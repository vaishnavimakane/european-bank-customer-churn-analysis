# European Bank Customer Churn Analysis

## Project Overview
This project analyses customer churn patterns in a European banking dataset containing 10,000 customer records. It compares churn rates across geographical, demographic, financial, product-related, and customer engagement segments.

## Objectives
- Calculate the overall customer churn rate.
- Compare churn across different customer segments.
- Identify segments with higher observed churn rates.
- Present insights through visualisations and an interactive dashboard.

## Tools and Technologies
- Microsoft Excel
- Python
- Pandas
- Plotly
- Streamlit

## Key Findings
- Overall churn rate: 20.37%
- Germany churn rate: 32.44%
- Churn rate among customers aged 46–60: 51.12%
- Inactive customer churn rate: 26.85%
- Active customer churn rate: 14.27%

## Project Files
- `app.py` — Streamlit dashboard application
- `European_Bank csv.csv` — Customer dataset
- `European_Bank_Churn_Analysis.xlsx` — Excel analysis workbook
- Project report PDF — Detailed methodology, findings, and recommendations

## How to Run the Dashboard
1. Install Python.
2. Install the required libraries by running:
   `pip install streamlit pandas plotly openpyxl`
3. Keep `app.py` and the CSV dataset in the same folder.
4. Run the dashboard:
   `streamlit run app.py`

## Conclusion
This project demonstrates how Excel, Python, and Streamlit can be used to analyse customer churn patterns and communicate insights for further business investigation.
